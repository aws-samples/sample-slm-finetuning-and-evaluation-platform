# Security

## Reporting a vulnerability

If you discover a potential security issue in this project, report it to AWS Security through the
[AWS vulnerability reporting page](https://aws.amazon.com/security/vulnerability-reporting/).

Do not create a public GitHub issue for a security finding. Public issues are visible to everyone
and can expose users of this project before a fix is available.

Please do not test for vulnerabilities against AWS-operated infrastructure. Deploy the sample into
an account you own and test there.

## Supported versions

This repository is a sample. Fixes are applied to the latest released version on the default
branch; earlier tags are not patched.
